# RealChart

## 주제
툴팁 활용하기

- RealChart에서 툴팁의 템플릿 문법, 텍스트 커스터마이징, 숫자·날짜 형식, 멀티 시리즈 통합, 크로스헤어·콜백·CSS 연동 등 툴팁 관련 기능을 전방위적으로 소개합니다.

## 라이브 데모

발표용 **Tooltip Playground**가 이 폴더에 포함되어 있습니다.

```bash
cd 2026-09/realchart
npm install
npm run dev
```

→ `http://localhost:5173/index.html`

자세한 실행 방법·Live Server 대안·폴더 구성은 [실행방법.md](./실행방법.md)를 참고하세요.
