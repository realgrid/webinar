# RealChart Tooltip Playground — 실행 방법

웨비나 라이브 시연용 **Tooltip Playground**를 이 폴더에서 바로 띄우는 방법입니다.

레이아웃: 왼쪽 데모 목록 → 가운데 차트 → 오른쪽 Monaco 에디터.  
에디터에서 `config`를 수정한 뒤 **적용**(⌘/Ctrl+S). 차트와 에디터 사이 스플리터로 너비를 조절할 수 있습니다.

> 저장소 루트(`webinar/`)에는 `package.json`이 없습니다. 반드시 이 폴더(`2026-09/realchart`)에서 명령을 실행하세요.

---

## 사전 준비

- **Node.js** 20.19 이상 또는 22.12 이상 (Vite 7 요구사항)
- 라이선스(`lib/realchart-lic.js`)는 **`localhost`** 에서만 동작합니다.  
  `127.0.0.1` 이나 `file://` 로 열면 차트가 안 나올 수 있습니다.

---

## 권장: Vite로 실행

터미널에서 이 폴더로 이동합니다.

```bash
cd 2026-09/realchart
npm install
npm run dev
```

브라우저가 `http://localhost:5173/index.html` 로 열립니다. (터미널에는 `http://localhost:5173/` 로 표시됩니다. 둘 다 동일합니다.)

특정 데모를 바로 열려면 `?demo=` 쿼리를 붙입니다.

```
http://localhost:5173/index.html?demo=scope
```

`demo` 값: `text` · `callback` · `list` · `format` · `scope` · `crosshair` · `shape` · `css`

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 (파일 저장 시 자동 갱신) |
| `npm run build` | `dist/` 빌드 |
| `npm run preview` | 빌드 결과 미리보기 (`http://localhost:4173/`) |

발표 중에는 에디터에서 config를 고친 뒤 **적용**만 누르면 됩니다.

- **원본 다시 불러오기** — 편집 내용을 버리고 해당 데모 JS 원본을 다시 로드합니다.
- 에디터 상단에서 폰트 크기를 조절할 수 있습니다. (브라우저에 저장됨)
- `tooltip-webinar-*.js` 파일을 직접 고쳐 저장해도 Vite가 페이지를 갱신합니다.

## 대안: Live Server

Vite 없이 VS Code / Cursor **Live Server** 로도 실행할 수 있습니다.

1. [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) 확장 설치
2. 이 `realchart` 폴더를 연 뒤 `index.html` 우클릭 → **Open with Live Server**  
   (또는 상태 표시줄 **Go Live**)
3. 이 폴더의 `.vscode/settings.json` 이 호스트를 **`localhost`** 로 지정하므로, 주소는 `http://localhost:5500/` 이어야 합니다.  
   만약 `http://127.0.0.1:5500/` 로 열리면 호스트만 `localhost` 로 바꿉니다.

`file://` 로 HTML을 직접 열면 데모 JS `fetch`가 막혀 동작하지 않습니다.

## 폴더 구성

| 경로 | 역할 |
|---|---|
| `index.html` | Tooltip Playground UI |
| `tooltip-webinar-playground.js` | 사이드 목록 · 에디터 · 차트 로드 |
| `tooltip-webinar-*.js` | 슬라이드 순서와 같은 데모 config |
| `lib/realchart.js` | RealChart 런타임 |
| `lib/realchart-lic.js` | localhost 라이선스 |
| `lib/realchart-style.css` | 스타일 |
| `package.json` · `vite.config.js` | Vite 개발 서버 (`host: localhost`, 시작 시 `index.html` 오픈) |
| `.vscode/settings.json` | Live Server 호스트를 `localhost` 로 고정 |

### 데모 목록 (슬라이드 순서)

1. **문구 만들기** — tooltipText · tooltipCallback · 목록 툴팁 · numberFormat · timeFormat
2. **범위 정하기** — scope
3. **위치 · 디자인** — crosshair · simpleMode · listMarker · style · CSS

## 문제 해결

| 증상 | 확인 |
|---|---|
| `Could not read package.json` | 저장소 루트가 아니라 `2026-09/realchart` 에서 `npm run dev` 했는지 |
| 차트가 안 보임 | 주소가 `localhost` 인지 (`127.0.0.1` / `file://` 아님) |
| 데모 목록만 있고 차트 오류 | 브라우저 콘솔 · `lib/realchart*.js` 로드 여부 |
| 데모 전환 시 빈 config | 같은 폴더의 `tooltip-webinar-*.js` 가 있는지 |
| 포트 충돌 | `npx vite --port 5174` 등으로 다른 포트 사용 |
| `Failed to load source map for realchart.js` | 무시해도 됩니다. (`lib/realchart.js.map` 이 없는 정상 경고) |

원본 개발 저장소의 데모를 수정했다면, 변경분을 이 폴더의 동일 파일명으로 다시 복사하면 됩니다.
