# 실행 방법

## 1. 실행

Node.js 20.19 이상 또는 22.12 이상에서 실행합니다. RealChart는 1.5.2 이상이 필요합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 localhost 주소를 열면 상단 **목록 보기**로 단계별 시작 데모를 선택할 수 있습니다. 발표는 다섯 단계이고 단계마다 시작 폴더가 하나씩 있습니다(`stages/1-split`~`5-selection`, 완성본은 `stages/final`). 시작 주소는 `/?demo=1-split&view=present`입니다. 발표 자료는 [2026-11-slides.pdf](./2026-11-slides.pdf)이며, 단계마다 데모 장에 요청문이 있습니다. HTML 파일을 `file://`로 직접 열지 않고 Vite 주소로 접속합니다.

각 섹션은 슬라이드의 설정·표시 예 설명 후 마지막 데모로 진행합니다. 데모는 14·19·25·30·35장에 있으며, 공유 화면을 반으로 나눠 왼쪽에 VS Code, 오른쪽에 데모 페이지를 두고 번갈아 확인합니다. 데모 페이지는 **목록 숨기기**를 누릅니다. 1920×1080 공유 화면, 데모 창 폭 약 960px, 브라우저 확대 100%에서 네 칸과 하단 축이 모두 보이는지 확인합니다. 1440px 미만에서는 목록을 처음부터 접으며 `view=list`로 열면 목록을 표시합니다. 창 폭이 1100px 이하면 차트를 창에 맞추고 제목 머리글을 숨깁니다.

RealChart 코어·Split·스타일은 `lib/`에 있습니다. 라이선스(`lib/realchart-lic.js`)는 **`localhost`** 에서만 동작합니다(2026-12-31까지).

## 2. 파일

```text
index.html           데모 목록(사이드바)
data.js              공통 데이터
stages/              발표 단계별 HTML과 main.js (완성본은 stages/final/)
style.css            화면 스타일
lib/                 RealChart 코어·Split·라이선스
vite.config.js       정적 라이브러리 경로 설정
2026-11-slides.pdf   발표 슬라이드
```

설정은 각 단계 `main.js` 상단의 `const config` 하나에 직접 작성했습니다. 행·열은 `config.split`, 축은 `config.xAxis`와 `config.yAxis`, 각 데이터 연결은 `config.series`에서 확인하세요. 데이터만 `data.js`로 분리했습니다. 다른 로컬 저장소나 프레임워크에 의존하지 않습니다.

## 3. 조작

- 초기 화면: 네 칸, 35분 집계, 선택 없음(손익은 텀블러)
- 상품 선택: 오른쪽 아래 손익만 갱신, 왼쪽 전체 추이는 유지. 선택이 풀리면 손익은 그대로
- 다음 5분 반영: 준비한 40분·45분 가상 응답을 한 번씩 반영. 상품 막대 선택은 풀리고 손익은 텀블러의 새 값. 두 번 반영하면 버튼 비활성화(처음 상태는 새로고침)
- 범례: pane 범례 항목을 누르면 시리즈를 숨기고, 다시 누르면 켭니다.

실시간 서버 연결은 포함하지 않습니다. 선택한 상품의 손익 갱신은 `config.general.onSelectionChanged`, 새 집계 반영은 차트 생성 아래의 버튼 처리입니다.

## 4. 빌드

```bash
npm run build
npm run preview
```

Vite 기본 빌드를 사용합니다. `lib/`는 Vite의 정적 파일 디렉터리로 지정해 별도 복사 코드 없이 빌드에 포함합니다. 이때 `lib/realchart-lic.js`도 `dist/`에 복사되므로, `dist/`를 공개 저장소나 공개 서버에 올릴 때는 라이선스 파일 포함 여부와 허용 도메인을 확인합니다.

## 집계 기준

매출·이익은 누적 금액이고 주문·취소는 5분 구간별 건수입니다. 금액 단위는 만 원입니다.

- 25분 기준: 실매출 5,000, 이익 1,400 = 상품별 이익 700 + 500 + 200
- 35분: 실매출 8,400, 이익 800 = 상품별 이익 -200 + 600 + 400
- 40분: 실매출 9,600, 이익 700 = -300 + 700 + 300
- 45분: 실매출 11,000, 이익 600 = -400 + 700 + 300
- 텀블러 35분: 정상가 매출 5,000 - 할인 1,400 = 실매출 3,600, 원가 3,000과 배송비 800 차감 후 이익 -200

전체 추이와 상품 상세는 같은 시점으로 갱신합니다.

25→45분 상품별 이익 변화는 텀블러 −1,100, 머그컵 +200, 드립백 +100으로 합계 −800입니다. 텀블러는 정상가 매출 +3,600, 할인 부담 −1,200, 원가 부담 −2,600, 배송 부담 −900을 합해 −1,100이 됩니다. 오른쪽 아래 워터폴은 현재 누적 손익이며, 차감 항목과 음수 이익은 `negativeColor`(빨강)로 표시합니다. 칸 제목은 숫자 없는 고정 문구입니다.

시간축에는 양 끝에 2.5분 여유를 두었습니다(`strictMin: -2.5`, `strictMax: 37.5`). 나란히 배치된 마지막 주문·취소 막대가 잘리지 않도록 갱신 후에도 새 시점 + 2.5분을 `strictMax`로 지정합니다.
